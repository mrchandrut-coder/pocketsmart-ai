# Demo Video Instructions

Record a short walkthrough that demonstrates the running application rather than only showing source code.

## Suggested Sequence

1. Introduce the problem and show the landing page.
2. Open the dashboard and identify the three planner options.
3. Submit one home plan and explain the budget and preferences used.
4. Submit one party or jewelry plan; show outfit-image input only if test data is safe to share.
5. Open recommendation history and show the generated entry.
6. Close with setup prerequisites and limitations: Gemini access is required, and current history/account data is in memory.

Use sample data, hide API keys and personal information, and verify the recording/link before sharing. Store approved screenshots under `Demo Screenshots/`.
