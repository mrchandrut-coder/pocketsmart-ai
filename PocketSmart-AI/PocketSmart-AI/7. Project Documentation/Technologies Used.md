# Technologies Used

| Technology | Use |
|---|---|
| Python | Application language |
| FastAPI | HTTP routes and API |
| Uvicorn | ASGI development server |
| Google GenAI SDK | Gemini recommendation generation |
| Jinja2 | Server-rendered HTML templates |
| Pydantic | Request and data models |
| python-jose and Passlib | JWT and password-hashing utilities used by authentication code |
| Pillow | Image-processing dependency |
| python-dotenv | Local environment configuration |
| HTML, CSS, JavaScript | Browser interface |

Exact dependency constraints are maintained in `5. Project Development Phase/requirements.txt`.
