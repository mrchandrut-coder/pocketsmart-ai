# Features

## Home Planner

Creates an interior plan from a budget, rooms, selected room types, style, preferred platforms, and free-text preferences.

## Party Planner

Creates an event budget plan using a budget, event type, guest count, venue/location, food preference, requested services, and notes.

## Jewelry Planner

Suggests jewelry using budget, occasion, preferred types, metal, platforms, and style. The request model also supports an optional outfit image for matching suggestions.

## History and Account Pages

The app includes landing, registration, login, dashboard, and history pages. Recommendations are stored in shared process memory, not durable per-user storage.
