# Hardware Requirements

## Development Minimum

- A modern desktop or laptop capable of running Python 3.10+.
- 4 GB RAM recommended for local development.
- Internet connectivity for installing dependencies and calling the Gemini API.
- A browser supporting current HTML, CSS, and JavaScript features.

## Hosting

No specialized hardware is required for a small demonstration deployment. Production capacity should be selected based on concurrent users, image sizes, and external API latency, then verified through load testing.
