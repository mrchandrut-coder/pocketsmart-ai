# Software Requirements

- Python 3.10 or newer.
- pip and a virtual environment tool (`venv` is included with Python).
- Dependencies listed in `5. Project Development Phase/requirements.txt`.
- Google Gemini API key configured as `GEMINI_API_KEY`.
- Modern web browser for the user interface.
- Optional `SECRET_KEY` environment variable for JWT signing; use a unique secret outside local development.

See `7. Project Documentation/Installation Guide.md` for setup instructions.
